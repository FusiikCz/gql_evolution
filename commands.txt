GQL Evolution - Quick Commands
================================

START APPLICATION (FULL SETUP - RECOMMENDED):
-----------------------------------------------
1. docker-compose up -d
3. Set environment variables:
   $env:DEMO="true"
   $env:GQLUG_ENDPOINT_URL="http://localhost:8000"
   $env:POSTGRES_HOST="localhost:5434"
   $env:OPENAI_API_KEY="dummy-key"
   $env:AZURE_COGNITIVE_ACCOUNT_NAME="dummy-account"
   $env:AZURE_CHAT_DEPLOYMENT_NAME="dummy-deployment"
   # Optional: pricing map for proxy cost_usd (USD per 1k tokens)
   # Example:
   # $env:OPENAI_MODEL_PRICING_JSON='{"gpt-4o-mini":{"prompt_per_1k":0.00015,"completion_per_1k":0.0006}}'
4. Start uvicorn:
   uvicorn main:app --reload


CHECK STATUS:
-------------
docker ps
netstat -an | findstr :8000

RESTART SERVER (after code changes):
-------------------------------------
1. Stop uvicorn: Ctrl+C
2. Start uvicorn: uvicorn main:app --reload
   (IMPORTANT: Restart is needed after DBDefinitions changes due to singleCall cache)

TESTING:
---------
# Spustit všechny testy
pytest tests/ -v

# Spustit jeden konkrétní test
pytest tests/test_endpoint_config.py::test_endpoint_config_insert -v
python tests/run_test.py test_endpoint_config_insert

# Spustit pouze failed testy
pytest tests/ --lf -v

# Zastavit po prvním failu
pytest tests/ -x -v

# Spustit podle kategorie
pytest tests/ -m "create" -v          # Pouze CREATE operace
pytest tests/ -m "read" -v            # Pouze READ operace
pytest tests/ -m "endpoint_config" -v  # Pouze EndpointConfig testy
pytest tests/ -m "crud" -v             # Všechny CRUD operace

# S code coverage
pytest tests/ --cov=src --cov-report=html
# Otevřít: htmlcov/index.html

# Bez coverage (rychlejší)
pytest tests/ --no-cov -v

TROUBLESHOOTING:
----------------
- If Docker fails: Start Docker Desktop first
- If database error: Check docker ps (postgres should be running)
- If port 8000 busy: netstat -an | findstr :8000
- For simple setup: Use POSTGRES_HOST="localhost:5432"
- For full setup: Use POSTGRES_HOST="localhost:5434"
